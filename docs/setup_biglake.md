# BigLake External Table Setup

dbt expects BigQuery to expose the Iceberg table as:

```text
<GCP_PROJECT_ID>.nyc_taxi_trust.yellow_trips_external
```

The ingestion step writes the Iceberg warehouse to the GCS path in `GCS_WAREHOUSE_PATH`.
After ingestion has created and synced the table metadata, create a BigLake external
table that points BigQuery at that Iceberg table.

## Prerequisites

- BigQuery API enabled.
- BigLake / BigQuery Connection API enabled.
- A GCS bucket matching `GCS_BUCKET`.
- A service account with access to BigQuery and the GCS warehouse path.
- Local environment variables loaded from `.env`.

```bash
set -a
source .env
set +a
```

## Create Datasets

```bash
bq --location="${BQ_LOCATION:-US}" mk --dataset "${GCP_PROJECT_ID}:${BQ_DATASET}"
bq --location="${BQ_LOCATION:-US}" mk --dataset "${GCP_PROJECT_ID}:${BQ_DATASET}_staging"
```

If the datasets already exist, `bq` will report that and you can continue.

## Create A BigQuery Connection

Create a Cloud Resource connection. The connection gives BigQuery an identity it can
use to read the Iceberg metadata and data files in GCS.

```bash
bq mk --connection \
  --location="${BQ_LOCATION:-US}" \
  --project_id="${GCP_PROJECT_ID}" \
  --connection_type=CLOUD_RESOURCE \
  nyc_taxi_iceberg
```

Fetch the connection service account:

```bash
bq show --connection \
  --location="${BQ_LOCATION:-US}" \
  --project_id="${GCP_PROJECT_ID}" \
  nyc_taxi_iceberg
```

Grant that service account read access to the bucket:

```bash
gcloud storage buckets add-iam-policy-binding "gs://${GCS_BUCKET}" \
  --member="serviceAccount:<CONNECTION_SERVICE_ACCOUNT>" \
  --role="roles/storage.objectViewer"
```

## Create The External Table

Find the Iceberg metadata file generated by ingestion:

```bash
gsutil ls "${GCS_WAREHOUSE_PATH}/yellow_taxi/trips/metadata/*.metadata.json"
```

Use the newest metadata file in the external table definition:

```sql
CREATE OR REPLACE EXTERNAL TABLE `<GCP_PROJECT_ID>.nyc_taxi_trust.yellow_trips_external`
WITH CONNECTION `<GCP_PROJECT_ID>.<BQ_LOCATION>.nyc_taxi_iceberg`
OPTIONS (
  format = 'ICEBERG',
  uris = ['gs://<BUCKET>/<WAREHOUSE_PATH>/yellow_taxi/trips/metadata/<LATEST>.metadata.json']
);
```

Run it with:

```bash
bq query --use_legacy_sql=false < create_yellow_trips_external.sql
```

## Validate

```bash
bq query --use_legacy_sql=false \
  "SELECT data_year, data_month, COUNT(*) AS rows
   FROM \`${GCP_PROJECT_ID}.${BQ_DATASET}.yellow_trips_external\`
   GROUP BY data_year, data_month
   ORDER BY data_year, data_month"
```

After this succeeds, dbt can build the downstream models:

```bash
dbt run --profiles-dir dbt --project-dir dbt
dbt test --profiles-dir dbt --project-dir dbt
```
